# ER-модель онлайн-магазину

## Опис домену

Онлайн-магазин — це система, у якій користувачі можуть переглядати товари, додавати їх до замовлень та оформлювати покупки.

Система повинна зберігати інформацію про користувачів, товари, категорії товарів, замовлення, позиції замовлень та платежі.

## Основні сутності

- Користувач (User) — інформація про покупця.
- Товар (Product) — інформація про товари магазину.
- Категорія (Category) — групування товарів.
- Замовлення (Order) — інформація про покупки.
- Позиція замовлення (OrderItem) — товари та їх кількість у замовленні.
- Платіж (Payment) — інформація про оплату замовлення.

## Мета

Побудувати нормалізовану ER-модель онлайн-магазину з коректними первинними та зовнішніми ключами, атрибутами й кардинальностями зв'язків.
