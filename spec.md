# Специфікація ER-моделі онлайн-магазину

## 1. Намір

Створити ER-модель бази даних онлайн-магазину для зберігання інформації про покупців, товари, категорії, замовлення та платежі.

## 2. Сутності

- User — покупець: id, name, email.
- Product — товар: id, name, price.
- Category — категорія: id, name.
- Order — замовлення: id, user_id, created_at, status.
- OrderItem — позиція замовлення: id, order_id, product_id, quantity, unit_price.
- Payment — платіж: id, order_id, amount, status.

## 3. Зв'язки

- User → Order: один до багатьох (1:N).
- Category → Product: один до багатьох (1:N).
- Order → OrderItem: один до багатьох (1:N).
- Product → OrderItem: один до багатьох (1:N).
- Order → Payment: один до багатьох (1:N).

## 4. Критерії прийняття

- AC-1: Модель містить усі 6 сутностей.
- AC-2: Кожна сутність має первинний ключ (PK).
- AC-3: Зовнішні ключі (FK) відповідають визначеним зв'язкам.
- AC-4: Усі зв'язки мають зазначену кардинальність.
- AC-5: Модель не містить зайвих дубльованих даних і відповідає принципам нормалізації.
- AC-6: ER-діаграма створена за допомогою Mermaid і відповідає специфікації.
- AC-7: Типи ідентифікаторів узгоджені між PK та відповідними FK.
- AC-8: Електронна адреса кожного користувача (User.email) є обов'язковою та унікальною (UNIQUE, NOT NULL).
